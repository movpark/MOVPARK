# MOVPARK starter website

A responsive, dark-cinematic, static website starter. It uses fictional demo catalogue entries and does not include copyrighted movies, streams, or third-party site code.

## Preview
Open `index.html` in a browser.

## Free hosting
1. Create a GitHub account and a new public repository named `movpark`.
2. Upload `index.html`.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub Pages will provide a free `github.io` address after deployment.

You can connect a custom domain later in **Settings → Pages → Custom domain**. A domain name itself usually costs money; free hosting does not make a paid domain free.

## Before launch
- Replace demo titles/posters with artwork you own or are licensed to use.
- Add only video sources you own or have permission to distribute.
- This is a front-end starter, not a full streaming backend or a clone of NetMirror.
